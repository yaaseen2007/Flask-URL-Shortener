# Flask URL Shortener

A simple URL shortener web application built using Python and Flask. It converts long URLs into shorter links that are easier to share.

## Features
- Enter a long URL
- Generate a shortened URL
- Redirect to the original website using the shortened link
- Simple web interface

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Note
This project helped me learn Flask routing, handling form inputs, and redirecting users between URLs.
